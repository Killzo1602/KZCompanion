# website/

This folder is the documentation site and landing page **inherited from DroidDeck** (upstream:
https://github.com/ggfto/DroidDeck). It still describes the removed button deck, profiles, automations and
Stream Deck import, and its links, images and download buttons point to the upstream project.

It is kept for attribution and as a reference for the integration and API pages, but it is **not**
KZ Companion documentation, and the `Pages` workflow is manual-only so it is never published by accident.

Before publishing a site for KZ Companion, rewrite or remove the legacy pages, replace the screenshots,
and update every download link. Current documentation lives in the repository root `README.md` and `docs/`.
