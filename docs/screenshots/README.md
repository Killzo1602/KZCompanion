# Screenshots to capture for the README

The README does not use images of the old DroidDeck button deck, and none have been invented. Real
screenshots of the current KZ Companion UI still need to be captured. Save them here with these names,
then add them to the README's **Screenshots** section.

| File | What to capture |
|---|---|
| `android-dashboard.png` | Android Dashboard with live CPU, GPU and RAM |
| `android-apps-running.png` | Android Apps page with the "Running now" section and Favorites |
| `windows-applications.png` | Windows configurator, **Applications** page |
| `windows-integrations.png` | Windows configurator, **Integrations** catalog |
| `windows-appearance.png` | Windows configurator, **Appearance** page |

Guidelines:

- Use the release build, at the final version, not a debug build.
- Capture with **demo data only**. Hide or crop anything personal: installed app lists, window titles,
  account names, IP addresses.
- **Never** show a pairing QR code, API key or token.
- Android: portrait or landscape as the product is used; PNG, about 1080 px on the short edge.
- Windows: the configurator in a browser window of about 1280 px width; PNG.
- Keep each file under about 500 KB (optimize with a PNG optimizer if needed).
