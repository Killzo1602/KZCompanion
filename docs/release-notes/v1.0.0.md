# KZ Companion v1.0.0

First public release. KZ Companion turns an Android phone into a live dashboard and remote control for a Windows PC.
It is a modified fork of [DroidDeck](https://github.com/ggfto/DroidDeck) by Gabriel Freitas.

## Downloads

| File | For |
|---|---|
| `KZCompanion-Setup-1.0.0.exe` | **Windows 10/11 x64**: installer, per-user, updates itself from GitHub Releases |
| `KZCompanion-Android-arm64-v1.0.0.apk` | **Android, ARM64 phones** (most phones made since about 2017) |
| `SHA256SUMS.txt` | Checksums of the two files above |
| `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md` | License and attribution notices |
| `*.nupkg`, `releases.win.json`, `assets.win.json`, `RELEASES` | Update feed used by the installed Windows app. Do not download these by hand. |

You need **both** the Windows app and the Android app.

## Features

- Live CPU, GPU and RAM on the Android Dashboard, plus a Hardware page. Sensors your hardware does not report (for example CPU temperature) show as unavailable.
- Windows audio mixer: master volume and mute, per-app volume and mute.
- Windows microphone mute and system-wide Deafen. These control the Windows devices, not Discord's own mute (that is the Discord integration).
- Favorites, application launching, installed application and game discovery (including Steam and Battle.net).
- Running Apps: Focus/Restore, Minimize and graceful Close (never a force kill).
- Appearance settings on Windows and Android.
- QR pairing with an API key; every request is authenticated.
- Optional integrations catalog.

## Install

1. **Windows:** run `KZCompanion-Setup-1.0.0.exe`. It installs for your user (no administrator rights needed) and starts in the system tray.
2. **Android:** copy the APK to the phone, allow installing from that source, install it.
3. On the PC, right-click the tray icon, choose **Pair device (QR)**, and scan the code in the Android app. Phone and PC must be on the same network.
4. When asked, allow the Windows Firewall rule for private networks (TCP 4787, UDP 7573).

Verify a download: `Get-FileHash .\KZCompanion-Setup-1.0.0.exe -Algorithm SHA256` and compare with `SHA256SUMS.txt`.

**Windows SmartScreen:** the installer is **not code-signed** in this release. Windows may show "Windows protected your PC".
Choose **More info**, then **Run anyway**, only after checking the checksum above.

## Known limitations

- Traffic between phone and PC is plain HTTP on the local network, with no end-to-end encryption. Use trusted networks.
- Windows installer is unsigned (see above). The Android APK is signed with KZ Dev Studio's release key; it **cannot be installed over an existing debug-signed
  installation** (for example one built from source): uninstall that one first and pair again.
- ARM64 Android only; there is no 32-bit or x86 build.
- Applications running as administrator are listed as locked and cannot be controlled.
- Some hardware sensors (CPU temperature and power) need an extra driver (PawnIO, installed from the tray menu) and administrator rights; otherwise they show as unavailable.
- Not tested on a physical device matrix; see the changelog for what was verified.
- The Android app's license is not fully settled upstream; see `NOTICE` and `docs/license-audit.md`.

## Experimental integrations

Integrations are optional and **not all have been tested with live accounts or devices** in this release; none is verified end to end.

| Integration | Status |
|---|---|
| Discord, Spotify, OBS Studio | Setup available. Discord's voice permissions are limited to approved apps or listed testers. Spotify needs Premium and your own developer app; "save to library" needs an update. OBS reads state only. |
| Apple Music | Candidate, unverified: depends on Windows media-session support. |
| Home Assistant, Philips Hue, Govee, MQTT, Twitch, YouTube Live | Backend only: no KZ setup screen. |
| Tuya / Smart Life | On hold. |
